# Claude the DM: project docs

Copies of the docs in the claude.ai "Claude the DM" project, kept here as a record. Chats read the claude.ai copies; when one changes there, copy it here too.

- `../DM_PROJECT_INSTRUCTIONS.md`: the project instructions (pasted into the project's Instructions box).
- `pixel-art-guide.md`: how pictures are made and sent during play.
- `cloud-hosting-brief.md`: build brief for moving the engine to the cloud server (2026-11-25).
- `party-ui-brief.md`: build brief for the Party Mode phone UI restyle (2026-11-16).
- `base-engine-audit.md`: why we built on dm20-protocol, the determinism audit, and the change log.

Campaign data (arc, characters, session notes, art) is not here: it lives on the server and is backed up by `backup_campaigns` to the private campaigns repo.
